
# PRD-FUNC-002 — User Management

# 1. 개요
## 1.1 목적

시스템 사용자의 계정을 생성하고, 자신의 사용자 정보를 확인하며, 자신의 비밀번호를 변경할 수 있도록 사용자 관리 기능의 요구사항을 정의한다.

본 문서는 사용자 기능이 무엇을 보장해야 하는가를 정의하며, 데이터 저장 방식이나 특정 구현 기술을 요구사항으로 규정하지 않는다.

## 1.2 범위

본 요구사항은 다음 사용자 기능을 대상으로 한다.

사용자 계정 생성
사용자 식별 정보 관리
자신의 사용자 정보 조회
자신의 비밀번호 변경
사용자 상태 관리의 기반 정보
사용자와 역할 정보의 연계

관리자에 의한 사용자 상태 변경 및 역할 관리의 구체적인 행위는 별도의 인가/RBAC 요구사항에서 정의한다.

## 2. Functional Requirements
FR-USER-001 — 사용자 계정 생성

시스템은 사용자가 필요한 사용자 정보를 제출하여 사용자 계정을 생성할 수 있도록 해야 한다.

사용자 계정 생성이 완료되면 시스템은 생성된 사용자를 식별할 수 있는 사용자 정보를 제공해야 한다.

FR-USER-002 — 사용자 식별 정보의 중복 방지

시스템은 동일한 사용자 식별 정보가 중복되어 사용자 계정이 생성되지 않도록 해야 한다.

현재 시스템에서 사용하는 사용자명과 이메일은 각각 중복 여부를 검증해야 한다.

중복된 사용자명 또는 이메일로 계정을 생성하려는 요청은 성공해서는 안 된다.

FR-USER-003 — 신규 사용자 상태

정상적으로 생성된 사용자 계정은 시스템이 정의한 초기 사용자 상태를 가져야 한다.

현재 신규 사용자는 활성 상태로 생성된다.

구체적인 상태 변경 권한 및 상태 기반 접근 제어는 Security/RBAC 요구사항에서 정의한다.

FR-USER-004 — 자신의 사용자 정보 조회

인증된 사용자는 자신의 사용자 정보를 조회할 수 있어야 한다.

사용자 정보 조회 결과에는 시스템이 사용자에게 제공하도록 정의한 식별 정보가 포함되어야 한다.

사용자는 자신의 정보 조회 과정에서 다른 사용자의 사용자 정보를 조회할 수 있어서는 안 된다.

FR-USER-005 — 사용자 역할 및 권한 정보 조회

시스템은 인증된 사용자의 현재 역할 및 권한 정보를 사용자 정보 조회 결과에 포함할 수 있어야 한다.

역할 및 권한의 실제 부여·변경 정책은 PRD-SEC-003-rbac에서 정의한다.

FR-USER-006 — 비밀번호 변경

인증된 사용자는 자신의 비밀번호를 변경할 수 있어야 한다.

비밀번호 변경 요청은 시스템이 정의한 비밀번호 정책을 만족해야 한다.

현재 구현에서는 8자 미만의 비밀번호 변경 요청을 허용하지 않는다.

FR-USER-007 — 비밀번호 변경 후 기존 인증 상태 처리

사용자의 비밀번호가 변경된 경우 기존 인증 상태가 계속 유효한지 여부는 시스템의 보안 정책에 따라 처리되어야 한다.

비밀번호 변경 이후 기존 Refresh Token을 무효화하는 정책은 PRD-SEC-004-token-invalidation에서 정의한다.

# 3. Functional Boundaries

본 문서에서는 다음 구현 세부사항을 요구하지 않는다.

특정 데이터베이스 기술
특정 ORM 또는 영속성 기술
특정 비밀번호 해시 알고리즘
특정 API 프레임워크
특정 캐시 또는 세션 저장소
특정 인증 토큰 기술

구현 및 기술 선택은 Architecture 및 ADR 문서에서 정의한다.

Acceptance Criteria는 실제 API 동작과 테스트 가능성을 기준으로 세부 조건을 정의한다.

# 6. Implementation Traceability

현재 구현에서 확인되는 주요 사용자 기능은 다음과 같다.
```txt
PRD-FUNC-002
    │
    ├── FR-USER-001
    │      └── UserController /signup
    │
    ├── FR-USER-004
    │      └── UserController /me
    │
    ├── FR-USER-005
    │      └── UserService.getMe()
    │
    └── FR-USER-006
           └── UserController /me/password
```

세부 구현 기술과 클래스 간 의존관계는 Architecture 문서에서 관리한다.
