- **Date:** 2026-08-26
- **Domain:** IAM (Role, Permission), Audit
- **Author:** AI Agent (Antigravity) & bluejck10113

## 1. 목적 (Purpose)
* Lombok(`@Getter`, `@Setter`)에 의존하던 구형 DTO 클래스를 Java 14+ 표준인 `record` 타입으로 변환.
* 데이터 전송 객체의 불변성(Immutability)을 강제하여 부작용(Side-effect) 방지.
* Entity 객체가 Controller 계층으로 직접 유출되는 것을 차단.

## 3. 핵심 변경 사항 (Key Changes)
1. **클래스 ➔ Record 변환:** 기존 `@Getter` 클래스들을 `public record ...`로 변경.
2. **정적 팩토리 메서드 적용:** `RoleResponse.from(Role role)`과 같이 Entity를 DTO로 변환하는 로직을 Record 내부에 캡슐화.
3. **Service & Test 코드 수정:** Record 변환에 따라 Getter 호출 방식이 `getName()`에서 `name()`으로 변경된 부분 일괄 수정 적용 및 테스트 통과 확인.
